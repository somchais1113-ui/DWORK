# AI image master source

`ai-hero-master.png` is the full-resolution, AI-generated master image used to create the bundled 18 sample images. Every `.webp` file is a distinct crop of that single master scene; repeated models/scenes are expected. These are **NOT original Figma images**.

To replace any asset, open `tools/image-manager.html` and upload your own licensed photo. The tool saves the final WebP with the exact expected filename; overwrite the file in the corresponding assets folder.

The master is a flattened PNG; this package does not include layered Photoshop/Illustrator/Figma sources.
